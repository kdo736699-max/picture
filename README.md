使用方法：
1. 将 index.html 部署到任意支持 HTTPS 的静态网站托管服务。
2. 得到公开网址后，把该网址放到你的 App/文章中。
3. 用户点击网址 → 点击“一键复制制作指令” → 打开豆包 → 上传照片 → 粘贴。

注意：
- 剪贴板 API 在 HTTPS 页面下兼容性最好。
- 页面包含旧版复制方式作为 fallback；若 App 内置浏览器仍限制复制，会显示可手动长按复制的文本框。
- 如需修改提示词，编辑 index.html 中 const PROMPT 对应内容即可。
